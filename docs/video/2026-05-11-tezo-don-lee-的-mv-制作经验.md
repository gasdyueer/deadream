# Tezo Don Lee 的MV制作经验

![](/images/video/2026-05-11-tezo-don-lee-%E7%9A%84-mv-%E5%88%B6%E4%BD%9C%E7%BB%8F%E9%AA%8C/%E9%9F%B3%E4%B9%90mv%E5%88%B6%E4%BD%9C%E5%88%9B%E6%84%8F%E8%BF%87%E7%A8%8B-%E5%93%94%E5%93%A9%E5%93%94%E5%93%A9-bilibili-bv1nfhaeuefa-%E5%AD%97%E5%B9%95%E6%80%9D%E7%BB%B4%E5%AF%BC%E5%9B%BE.jpg)

这份文档详细拆解了音乐视频（MV）导演从接到委托到创意成型的完整心路历程。为了让你更深入地理解这一过程，我将以文档中的《Death Letter》项目为引子，将这个工作流程提炼为五个标准化的阶段，并为每个阶段提供普适性的操作建议和方法论。

---

### 🎵 第一阶段：音乐解构与情感锚定

这是创意的萌芽期，核心任务是“听懂”音乐，不仅仅是旋律，更是其内在的结构和情绪。

- **文档案例复盘**：
    
    - **素材**：导演收到的是 Demo 小样。
    - **方法**：反复听到厌倦，以捕捉细节；通过翻译歌词（英译韩），理解其隐喻（离别、抓住恋人）。
    - **产出**：确定了“面临离别”的情感基调，以及“Desert”（荒漠/临终低语）的关键词。
- **💡 普遍性建议与工作流程**：
    
    1. **建立“听觉笔记”**：不要只用耳朵听，要动笔记录。标记出前奏、主歌、副歌、桥段和尾声的节点。
    2. **情绪曲线图**：在听歌时，画出一条情绪曲线。哪里是压抑的？哪里是爆发的？哪里是喘息的？这将决定你视频的节奏。
    3. **关键词提炼法**：像导演处理“Desuit”一样，为歌曲提炼 3-5 个核心关键词（例如：赛博朋克、孤独、奔跑、记忆）。这些关键词将成为后续视觉搜索的指南。
    4. **“反向思维”练习**：文档中提到了一个很棒的技巧——**反向表现**。例如歌词说“节省呼吸”，画面却表现“呼出冷气”。尝试为你的歌曲找到这种意料之外的视觉对应物。

### 📝 第二阶段：故事架构与逻辑编织

在明确了情感基调后，需要构建一个物理上的故事框架，让情感有处安放。

- **文档案例复盘**：
    
    - **灵感来源**：极地自然景观。
    - **故事线**：离别后 -> 寻找回忆地点 -> 记忆与现实交织 -> 情感燃烧（高潮） -> 完成旅程离开。
    - **空间逻辑**：确立了“从左到右”（到达）和“从右到左”（离开）的物理移动方向，增强观众的潜意识理解。
- **💡 普遍性建议与工作流程**：
    
    1. **确立叙事视角**：是第一人称的主观体验，还是上帝视角的客观记录？是线性叙事，还是碎片化回忆？
    2. **构建“旅程”模型**：大多数 MV 都遵循一种“旅程”结构（物理上的或心理上的）。你需要明确：
        - **起点**：主人公的状态。
        - **触发点**：什么事件打破了平衡？
        - **冲突/高潮**：情感最激烈的地方。
        - **终点**：主人公的最终归宿。
    3. **空间与方向的隐喻**：利用空间移动来隐喻情绪变化。
        - _通用法则_：向右通常代表希望/前进，向左代表回归/消沉；向上代表升华，向下代表堕落/潜意识。利用这些视觉心理学法则来引导观众。

### 🎨 第三阶段：视觉开发与素材拼图

这一阶段是将抽象的文字和情感转化为具体的视觉图像。

- **文档案例复盘**：
    
    - **视觉要素**：冰川、冰山、光线不足的天空、长影子、摇曳的头发。
    - **对比构建**：将“冷酷巨大的自然”与“微小的人类情感”进行对比。
    - **调研**：寻找极地纪录片、电影截图作为参考。
- **💡 普遍性建议与工作流程**：
    
    1. **制作“情绪板”**：使用 Pinterest、Eagle 等工具，收集颜色、光影、构图、服装、妆容的参考图。确保所有图片都符合第一阶段提炼的关键词。
    2. **色彩与色调规划**：决定你的主色调。是高饱和的撞色，还是低饱和的莫兰迪色？冷色调通常传达疏离、冷静或悲伤，暖色调传达热情或回忆。
    3. **寻找“视觉锚点”**：确定几个核心视觉符号（如文档中的“呼出的冷气”）。这些符号将在视频中反复出现，形成视觉母题。
    4. **利用 AI 辅助**：你可以使用 AI 绘画工具，根据你的关键词生成概念图，快速验证你的视觉构想是否符合音乐氛围。

### 🖼️ 第四阶段：视觉化呈现与沟通

有了想法还不够，你需要将其转化为团队和客户都能理解的语言。

- **文档案例复盘**：
    
    - **风格框架**：制作了约 3 张关键帧（Style Frame），包含主人公形象和高潮场景。
    - **草图与故事板**：将粗糙想法细化，特别是相机晃动的测试镜头。
- **💡 普遍性建议与工作流程**：
    
    1. **风格框架**：这是沟通的基石。选择视频中最具代表性的三个瞬间（开头、高潮、结尾），制作成高质量的静态图。这能锁定整体美术风格。
    2. **动态分镜**：对于复杂的运镜（如文档中提到的相机晃动），制作简单的动态分镜或参考视频。你可以用手机拍一段粗略的视频来演示你想表达的节奏。
    3. **明确技术参数**：在分镜中注明镜头类型（广角、长焦）、运动方式（推拉摇移）、焦段和景深，确保摄影师能准确执行。

### ✂️ 第五阶段：拍摄执行与后期整合

这是将蓝图变为现实的阶段，也是文档中提到的“最令人兴奋的部分”。

- **文档案例复盘**：
    
    - **画面构成**：采用4:3画幅，利用画面各处讲故事。
    - **情感编排**：静态构图容纳大自然，中间穿插粗糙绘画感的特写来解释情感，形成动静对比。
- **💡 普遍性建议与工作流程**：
    
    1. **画幅与构图**：不要局限于16:9。像文档中一样，尝试4:3或 2.35:1等电影画幅，能瞬间提升质感。
    2. **动静结合**：避免画面单调。如果背景是静态的大自然，人物就要有动态（如被风吹动）；如果画面整体是动态的，需要寻找一个静态的视觉焦点。
    3. **后期调色**：调色是确立 MV 风格的最后一道关卡。根据你的风格框架进行调色，确保全片视觉统一。
    4. **音画同步**：在剪辑时，不仅要对准节拍，还要对准情绪。利用剪辑点（Cut）来匹配音乐的重音或歌词的转折。

通过这五个阶段的系统化操作，你可以将任何一首复杂的音乐，转化为一个结构清晰、情感饱满、视觉震撼的 MV 作品。
