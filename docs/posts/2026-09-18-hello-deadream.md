# 你好，deadream

又开了一个博客。

写博客这件事的收益从来不是立刻兑现的：真正值钱的是六个月后回头看，发现自己当时是怎么想的、踩了哪些坑、为什么做了那个决定。代码会留在仓库里，但推理过程不会 —— 除非当时写下来了。

## 这里准备写什么

- 工程笔记：具体到文件、行号和失败的报错，而不是「最佳实践」清单。
- 读书与思考：读完之后的结论，以及被推翻的旧结论。
- 零碎记录：不足以成文，但丢了可惜的东西。

## 站点是怎么搭的

VitePress + GitHub Pages。没有评论、没有统计、没有广告，只有 Markdown 和一次 `git push`。

文章存放在 `docs/posts/`，文件名以日期开头，frontmatter 里写标题、标签、摘要。推送到 `main` 之后，GitHub Actions 会自动构建、部署，并把本次推送新增/更新/删除了哪些文章写进运行摘要里。
